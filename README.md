# CV-Customizer

I made this dashboard to experiment a bit with Chat-GPT's API. 

It is meant to help me customize my CV according to job ads, starting from a ChatGPT-generated answer. There is a configuration file containing my CV, and it automatically queries ChatGPT to improve the bullet points and all other parts of the CV based on the job description. You can then quickly review the result and compile and download the CV to the job portal of your choice. 

It can also generate answers to questions in an application form based on the experience in your CV.

It still is a work in progress, and uses the same rough structure as [my other dashboard project](https://github.com/MarcoTamb/Phlegraean-Fields). I suggest you have a look at that first as it is a much better project. 

However, if you are specifically interested in seeing some experience with AI, there are some callbacks in home.py calling out to ChatGPT to generate the required text. (when this was being worked on, gpt-4o was a bleeding edge model - it is a bit old)

No, I am not using this anymore to improve my CV and application material.
